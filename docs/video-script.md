# Short video script

About 35–45 seconds. Use the first-person claim only if the $60 bill is yours. Show a real tested installation; until then, label footage as a setup guide or demo. No monthly/yearly period is assumed.

| Time | Shot | Voiceover |
| --- | --- | --- |
| 0–5s | Subscription price, with personal details hidden | “My alarm subscription costs $60. Could I switch to a setup I control in Apple Home?” |
| 5–13s | Compatible door sensor, then Home Assistant and Alarmo | “Here's the DIY approach: compatible sensors feed Home Assistant, and Alarmo handles the alarm rules.” |
| 13–20s | Apple Home security-system tile | “HomeKit Bridge brings the alarm into Apple Home, so I can arm it and check its status.” |
| 20–27s | Supervised door test and Telegram alert | “When the alarm triggers, Telegram sends an alert. FRITZ!Box can also add an optional presence reminder.” |
| 27–34s | Setup guide and test checklist | “This is self-monitoring. Check your hardware and test everything before cancelling a monitored service.” |
| 34–42s | Repository README and end card | “I've put the starter config and setup guide in an open-source repo. Comment ‘home’ and I'll send you the link.” |

End-card text: **Apple Home + Telegram · Open-source setup guide · Comment “home”**

Caption: **Exploring a DIY alternative to my $60 alarm subscription with Apple Home, Home Assistant, and Telegram. Starter config and setup guide are open source. Comment “home” and I'll send you the link.**
